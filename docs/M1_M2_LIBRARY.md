# 第一批可用资料功能：公共基础、漫画与图片

日期：2026-09-19。延续已确认的 Lumoswitch Global 界面，本次开放漫画、图片、个人照片，以及登录、上传任务、回收站和本地加密备份。小说与两类私密空间仍按后续阶段开发；此批次不代表六类功能或生产部署全部完成。

## 已接入的操作

- 首次设置单用户登录密码；之后输入密码登录，可退出。密码保存为 bcrypt 散列；会话随机生成、仅 HttpOnly / SameSite Cookie 保存、24 小时过期，重启失效。写操作检查会话 CSRF 令牌，Host / Origin / 跨站检查继续生效。原件和预览也必须登录。
- 漫画：选择一层文件夹，预览页序，填写名称、逗号分隔的标签。隐藏文件忽略；嵌套目录、不支持格式和过大文件需显式处理或排除。服务端按自然数字排序；所有页确认成功后事务入库。同名书籍保留独立编号。
- 漫画列表显示第一页；名称包含搜索，多标签取交集；支持修改名称和标签，使用修订号避免并发覆盖。逐页 / 连续阅读，页码跳转，服务端记录阅读进度；整本 ZIP 从不可变原件输出，页名为 `00001.webp` 等。
- 有效静态 WebP 原字节保留；PNG/JPEG 按 M0 约定无损转换、重新解码核对像素。当前单文件上限仍为 64 MiB、4000 万像素，每本最多 3000 页。不接受动画漫画及 16 位 PNG。
- 图片：批量上传 JPEG / PNG / WebP / GIF、列表网格、随机照片墙、大图、单张及最多 100 张打包下载。随机轮次固定当时的数据范围，以稳定排序游标翻页；新增下一轮出现，删除不导致已浏览内容重复。
- 个人照片：批量保存原始文件，网格和取回原件，保留全部原字节及元数据。浏览器不支持的格式显示文件卡片。图片 / 照片不要求标题、标签或搜索，彼此独立。
- 上传：每本漫画 / 每张图片都有持久任务编号。每个文件先核对 SHA-256、持久化不可变原件，再记录任务进度；服务重启或网络中断后，可重新选择原文件继续。成功页不会再创建副本。当前重试粒度是单个文件，尚无文件内部的分块续传。需要保留上传页面；后台浏览器关闭后重新选择来源继续。
- 删除进入回收站，可恢复到原模块。开发版暂不永久删除，不自动清空；30 天保留和清理策略在后续阶段补齐。
- 备份中心显示配置状态、最近成功内容截止时间、完整性检查结果和快照编号。手动备份生成一致性 SQLite 快照，固定不可变文件版本，再调用 restic 加密备份及全量读取检查。失败不会刷新最近成功备份时间。

缩略图是独立的可重建 JPEG 副本；下载始终读取原件。带方向元数据的图片暂直接使用原图预览，交给浏览器应用方向，避免缩略图转向错误。不支持主动内容同源预览，未知格式仅允许作为附件下载。

## 启动与数据目录

构建后双击 `start.command`。默认自动初始化操作系统应用数据目录中的 `SRICS Next/library`；macOS 位于 `~/Library/Application Support/SRICS Next/library`。首次页面由使用者设置密码，没有默认用户密码。安装标记单独保存在上一级；初始化后资料目录缺失会停止，不会悄悄重建空库。

自定义数据盘需要显式初始化新目录，父目录需已存在：

```sh
./bin/srics init --data '/Volumes/Data/SRICS-library'
./bin/srics serve --data '/Volumes/Data/SRICS-library'
```

已有目录拒绝覆盖。不识别或较新的数据格式拒绝打开。同一库仅允许一个服务进程使用；请求会检查目录标识和数据库文件身份，避免继续使用被移除或替换的资料盘。预留 128 MiB 磁盘空间；写入失败不会作为上传完成。

当前仍只监听本机，默认 `http://127.0.0.1:19473`。局域网 HTTPS、后台启动、完整发布包与依赖随包分发留在 M5。

## 本地加密备份与独立恢复

备份口令与登录密码分开。先在设备之外妥善留存备份口令，再将口令写入仅本人可读的本机文件；不要把口令或文件放进源码仓库。用绝对路径设置并启动：

```sh
export SRICS_BACKUP_REPOSITORY='/Volumes/Backup/SRICS-restic'
export SRICS_BACKUP_PASSWORD_FILE='/安全位置/backup-password.txt'
./start.command
```

配置后点击“备份中心 → 立即备份”。支持新建空仓库或已有正确口令的 restic 仓库；非空非 restic 目录拒绝初始化。本次仅接入手动本地备份，自动计划、云端目标及保留策略未实现。

恢复默认写入一个不存在的新目录，并检查索引引用和文件 SHA-256：

```sh
./bin/srics restore \
  --repo '/Volumes/Backup/SRICS-restic' \
  --password-file '/安全位置/backup-password.txt' \
  --snapshot '备份中心显示的完整快照编号' \
  --target '/Volumes/Restore/SRICS-restored'
./bin/srics serve --data '/Volumes/Restore/SRICS-restored'
```

恢复后使用原登录密码。旧的浏览器会话不恢复。缺失文件或校验失败会返回非零退出码，已有目标拒绝覆盖；失败的恢复目录保留供检查，不自动覆盖重试。

普通资料的本地存储仍是明文；只有备份通过 restic 加密。私密照片和个人文件尚未开放，不能用普通图片 / 照片空间代替独立保险库。
