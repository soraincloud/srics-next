# 2026-09-28 第四轮检查：失败场景与恢复保证

基线 `afd312f`（rc5），修复版本 **0.3.0-rc6**。本轮重点检查“有恢复文件，但备份或私密恢复记录已经损坏”时的行为。数据库版本仍为 4，无新增迁移；未修改真实资料、真实密钥或云端资源。

## 恢复密钥能保证什么

正确、已启用的完整恢复 JSON，加上完整且匹配的备份仓库，可以解锁所选快照里的普通及私密资料；日常密码遗失不影响这一恢复途径。此前六类资料的独立进程演练继续作为回归。

恢复密钥本身不会保存你的文件，也无法补回未上传、未备份、被永久删除或已损坏且没有其他副本的内容。App 中显示“已验证”是最近一次验证记录，不表示今后的每次备份都成功。必须把导出的 JSON 实际另存离线，不能只依赖旧机器上的设置或界面的密钥编号。

本轮特意把临时仓库的所有 data 数据包移走，保留仓库配置、密钥、快照描述和正确恢复 JSON：完整读取校验及恢复均明确失败，没有生成恢复成功记录。这直接验证了“有密钥”不能替代“有完整数据”。

## 复现与修复

| 问题 | 修复前 | rc6 行为 |
| --- | --- | --- |
| 损坏恢复记录被快照静默忽略 | 用合成资料注入畸形 JSON、缺失私密身份封装、有效的活动密钥编号但没有对应记录。快照仍成功，只是不携带相应恢复标记；后续备份与保留流程可能继续。 | 快照创建时验证恢复记录格式、编号、仓库与资料库标识、状态和活动记录引用。异常会停止快照并清理未完成的暂存目录，不继续发布正常备份。已存在且合法、但创建于私密区启用前的记录仍保留，只不标记为覆盖新私密区。 |
| 密钥恢复过早写入成功记录 | 在合成备份中翻转私密恢复身份封装的一个字节。restic 仓库和库内文件哈希仍通过，但该恢复文件不能解开私密区；旧恢复入口仍返回成功并写入 `.srics-recovery.json`。 | 使用恢复文件恢复时，在成功记录之前实际解开私密索引，并调用完整原件读取校验，检查私密原件的解密认证、大小和明文 SHA；同时校验私密预览及回收站私密条目。失败保留已恢复目录供诊断，不确认恢复成功。 |

恢复密钥的初次确认也从“解密私密索引”扩展为“校验全部已保存私密原件和预览”，通过后再完成登记及备份确认。校验只在内存中处理明文，不产生明文临时文件；大资料库会增加读取时间。

此改动不更改备份口令或私密内容的加密格式。旧备份仍可读取；使用日常备份口令恢复而未提供恢复 JSON 时，继续只验证密文完整性，解锁私密区仍需原私密口令，不能把它描述为已验证私密明文。

## 故障注入和验证

- `TestDamagedRecoveryRecordStopsSnapshot`：三种损坏在 rc5 复现误成功，修复后均拒绝创建快照。
- `TestRecoveryRejectsUnreadableVaultBeforeSuccessReceipt`：使用真实 restic，分别测试恢复身份封装损坏、私密明文大小与加密索引不一致、仓库数据块缺失。前两种测试刻意保留可通过普通密文哈希检查的夹具，以确认实际解密校验有效；三个场景都不留下成功凭据。
- `TestFailedReadCheckPreservesLastSuccessAndSkipsRetention`：模拟备份上传返回新快照，但随后完整读取校验失败。状态为失败，保留原成功快照及时间，且不执行历史清理。
- 修复后的定向 race 测试通过，包括只用备份与恢复文件恢复全部六类资料的独立进程演练。新增损坏场景与保留保护测试分别通过。
- 主程序源码漏洞扫描：0 可达漏洞、0 已导入包漏洞；模块图仍保留未导入的 `x/crypto/openpgp` 告警 GO-2026-5932。NPM 扫描为 0。本轮未更改第三方依赖，随包 restic 的安全扫描沿用上一轮相同固定依赖的记录。

- `scripts/check.sh` 完整通过：前端构建与 18 项测试、Go vet、全部 Go race 测试、五个包的集成测试、11 项样本验证。六类资料仅用备份和恢复文件取回的演练再次通过。
- 最终 App 编译和严格签名完整性检查通过，包内版本为 rc6。仅保留系统 PATH 时，随包工具完成全部 11 项样本验证；后台进程崩溃后重启、重复启停、端口冲突、登录与会话失效、配置锁、更新前备份及重启验证通过。

## 仍然不能承诺的部分

日常自动备份在私密区锁定时执行，不留存恢复秘密，因此不能每次实际解开恢复身份封装。格式合法但密文内部损坏的恢复记录，以及看起来合法的索引内容改写，并不都能由结构和文件哈希检查识别；需要离线密钥参与的恢复演练。此版没有将“校验通过”解释成没有未知漏洞或所有硬件故障都可恢复。

独立 Mac＋云备份的部署仍需完成真实云端备份与完整读取校验、云账号恢复方式及历史版本保护、恢复 JSON 离线副本，以及另一台机器上的实际恢复。云账号访问权限与恢复解密密钥是两件事。真实云端验收前不应删除其他源文件副本。

此前报告中有关备份失败缺少外部通知、FileVault 解锁和登录前服务不运行、强制结束进程后可能留下 staging 暂存快照、尚未进行实际断电或 100 GB 真实负载测试的限制继续有效。
