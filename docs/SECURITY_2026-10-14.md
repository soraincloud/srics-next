# 2026-10-14 照片导入与安全复查

范围：待发布的照片原件保留、macOS ImageIO 预览、实况照片容器、私密媒体接口，以及服务和随包备份工具的依赖。测试使用独立临时资料库和合成图片、视频，未改动实际资料库。

## 已修正

- 私密实况照片续传时，文件选择器可同时选择照片和 MOV；提示明确说明需要两份原件。
- 前后端按 NFC 标准化与 Unicode 小写规则比较配对名称；保留容器中的原始文件名和全部字节。
- 在异步读取、CRC 计算及归档完成后检查取消状态，防止暂停操作之后继续准备上传。
- 将服务与随包 restic 的构建工具链从 Go 1.27.1 更新到 1.27.2，并将 x/net 更新至 0.60.0、x/crypto 更新至 0.57.0。初始调用分析报告 10 项标准库可达漏洞，涉及 HTTP、HTTP/2、MIME 和 TLS。可达性并不代表每项都能在当前部署中被利用。

上游依据：[Go 1.27.2 安全修复](https://go.dev/doc/devel/release#go1.27.2)、[HTTP/2 漏洞及 x/net 修复版本](https://pkg.go.dev/vuln/GO-2026-6617)。restic 保持 0.19.1，未修改上游源码或备份格式；仅更新构建工具链与固定依赖。恢复 JSON 和资料库结构保持兼容。

## 验证范围

- 前端配对、取消、确定性归档与断点续传测试，以及 TypeScript 和生产构建。
- Go 静态检查与竞态测试；容器损坏、非法路径、额外成员和压缩成员的拒绝检查。
- HEIC/AVIF/BMP/TIFF 原生解码、WebP 像素比对和再次导入不重编码。
- 公共和私密原件下载、动态视频读取、锁定后拒绝访问，以及原资料库删除后的独立恢复。
- 删除原系统、配置和口令后，仅凭完整备份与恢复 JSON 导出全部测试原件，逐字节核对。
- npm audit、服务 govulncheck、随包 restic govulncheck，以及源码分发隐私检查。

本次详细结果保存在本地 reports；结果仅代表本次测试和公开漏洞数据库覆盖的范围。实况照片仍按文件名配对，浏览器播放能力和 Apple 软件重新识别需在实际设备上验收。

更新后的服务与 restic 源码扫描均报告 0 项可达漏洞，npm audit 报告 0 项漏洞。x/crypto 模块的报告涉及未导入、未调用的 openpgp 包，本系统和随包 restic 不使用该包；此结果不等于整个模块没有已知问题。
