# 统一备份与恢复

Build 23 起，日常只需要保管两种东西：

1. 一份或多份不同日期的 **`.sricsbackup` 加密备份文件**。
2. 此资料库的一份 **恢复 JSON**，与备份分开离线保管。

登录密码用于网页；保险库口令用于私密资料。JSON 只用于系统损坏、原机或密码丢失后的备份恢复，不用于日常改密。完整、未损坏的包与匹配 JSON 可以恢复备份时保存的全部六类资料，包括私密原文件，无需原机器、配置或日常密码。只能恢复已经备份的内容。

## 首次设置

停止服务并保存配置，App → 备份 → 开始设置：

1. 保存恢复 JSON。已有私密资料时验证现有保险库口令一次，使应急钥匙也覆盖私密资料；口令不会写入 JSON。
2. 重新选择保存的 JSON，验证文件能读取并逐项校验私密原件。
3. 选择独立硬盘、普通目录、OneDrive 等网盘同步目录；需要直接云端自动备份时，可选 S3 并填写云服务商提供的账号访问密钥。无需准备口令文件或凭据 JSON。
4. 创建第一份备份。完整读取校验通过后完成设置。云端还会完整下载读回校验。

中途失败可以继续使用原 JSON 重试。已经验证的 JSON 不会被另一把钥匙静默替换。新设置不转换或删除已有旧仓库、旧包与旧 JSON。

## 日常备份

网页 → 备份 → 立即备份，或 App 中开启每天自动备份。App → 另存一份备份可选其他目录，格式完全相同，不要求再次拿出 JSON。修改密码、首次启用私密区、更换保存位置或重建内部缓存，继续保管原 JSON。

每份文件都是可独立恢复的完整加密包，包含数据库、普通 / 私密原件、照片、漫画、小说、修订、回收站及恢复记录。完整包会占用额外空间，S3 每次上传并读回全部文件，可能产生流量费用。OneDrive 等同步软件需等待上传完成；程序只能确认本地文件，不代替网盘同步验收。

保留全部日期文件。内部 restic 缓存由程序管理，用于生成快照与去重；输出验证成功后只整理内部缓存，不删除已发布备份。普通或私密原文件不会再次编码，WebP 原字节保持不变。

## 从备份恢复 / 换 Mac

1. 在新 Mac 安装同版或更新版 App。下载完整的一份 `.sricsbackup`，准备原恢复 JSON。
2. App → 从备份恢复，选择包、JSON 和导入位置。下一步选择新的资料目录，恢复并校验。导入和恢复各需要一份空间，原包不会修改。
3. 私密原件也使用 JSON 解锁并逐项验证。可直接取回单项文件，或为恢复副本设置新的登录密码与保险库口令，再启用资料库。
4. 在新 Mac 重新选备份位置、填写云账号、配置网络；资料库中的公开恢复记录保留，继续使用原 JSON。新机验收与备份完成前保留旧副本。

从 S3 下载包仍需要云账号，但下载完整后，解密只需包与 JSON。JSON 不替代云账号的访问和找回方式。复制到 U 盘或同步目录后的新版 JSON 不要求保留 POSIX 权限，但文件包含秘密，应单独妥善保存。

## 文件内部与长期迁移

恢复 JSON v2 含资料库 ID、公开接收地址、指纹、创建时间和 age X25519 秘密身份；不含登录密码、保险库口令、日常备份密码或 S3 访问凭据。程序数据库仅保留公开接收地址和加密后的私密身份，不保存 JSON 的秘密。

包 v2 使用流式 ZIP64 Store，内部包含加密 restic 仓库与 `srics-package.json` 公共清单。清单包含 SHA-256 / 大小、最新快照、资料库及钥匙编号，以及用恢复公钥加密的仓库解锁封装。无明文原件或秘密 JSON。

未来若 App 不可运行：读取 JSON 的 `secret` 作为 age identity，解密清单的 base64 `recoveryEnvelope`，得到 restic password、repositoryID 与 snapshot。解压加密仓库，用该 password 和 restic 恢复 snapshot；从 SQLite `settings/recovery-unified` 读取 base64 `wrappedVault`，用同一个 age identity 解密，得到用于私密对象的 X25519 identity。名称、对象关系和密文格式保留在数据库及源码中。请保存本说明和源码。

旧 JSON v1、旧 restic 仓库与包 v1 从“兼容旧版备份仓库”恢复；旧包也可直接选择包与其旧 JSON。它们仍需当时的对应 JSON，不会自动改用新版钥匙。详见 [旧版说明](RECOVERY_KEY_LEGACY.md)。

恢复钥匙不能修复已损坏的备份，也不能找回没有完成备份的修改。正式部署后请保留多个历史日期，并用实际云账号做一次新目录恢复验收。
