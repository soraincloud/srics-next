# 本机程序与后台管理

当前适用于 v0.3.0-rc18 · Build 24。普通使用先看 [安装与使用](TRIAL_INSTALL.md)；备份操作以 [统一备份与恢复](RECOVERY_KEY.md) 为准。

## App 与网页

- 网页管理资料：浏览、上传、编辑、搜索、标签、下载与回收站。
- App 管理部署：服务、登录密码、保险库口令、备份、资料迁移、空间设置与版本更新。
- 默认仅本机访问。局域网使用 HTTPS，需在访问设备上信任导出的公共证书。
- 关闭 App 窗口不会停止后台服务；点击“停止服务”才会停止。修改配置前先停止服务。
- “登录电脑后自动启动”和“异常退出后自动重启”是可选设置；自启依赖 macOS 用户登录，不能视为未登录时的系统服务。

## 配置与资料

默认配置目录是 `~/Library/Application Support/SRICS Next/`，默认资料目录是其中的 `library`。首次可选择其他资料位置；保存后通过“迁移资料目录”移动资料，不能直接改路径替代迁移。

| 内容 | 位置与用途 |
| --- | --- |
| `config.json` | 资料路径、网络、时间与备份设置；权限 600 |
| `library/` 或所选资料目录 | 数据库、分类原件、私密密文、回收站、修订及上传进度 |
| `backup-cache/` | 程序管理的内部备份缓存与日常加密钥匙，无需手工配置 |
| `backup-access/` | 程序管理的云账号访问凭据，权限受限，不放入备份包 |
| `https/` | 本机 HTTPS 公共证书与私钥；仅导出公共证书 |
| `service.plist` | 当前 macOS 用户的后台运行参数 |
| `service.log` | 运行日志；App 中可打开 |
| `.manager.lock` | 防止并发设置、启停和恢复切换 |

登录密码的 bcrypt 散列和受保险库口令保护的私密身份保存在数据库。普通配置不保存登录密码或保险库口令正文。恢复 JSON 的秘密只导出给用户，不保存在资料库；库内保存公开恢复记录和加密封装。

已配置资料盘缺失、数据库损坏或目录无法识别时拒绝启动，不自动建立同名空库。`.app` 只含程序，不含资料和个人配置。真实文件不应手工塞入系统内部目录，应通过网页导入。

## 备份、迁移与更新

首次备份在 App 中按“保存 JSON → 验证 → 选择位置 → 创建第一份备份”操作。之后网页可立即备份，App 可设置每天自动备份或另存一份。所有新输出使用 `.sricsbackup`；不要求用户创建备份口令文件或云端凭据 JSON。

迁移目录会停止服务，复制一致性资料库并逐文件校验，再切换位置；原目录与恢复 JSON 保留。备份保存位置、云账号和 HTTPS 属于设备设置，仍在原处。

换设备或丢失日常密码时，进入独立“从备份恢复”，选择完整包和匹配 JSON，恢复到新目录。可以取回单项原文件，也可以为恢复副本设置新密码并启用。新设备重新选择备份位置，仍使用原资料库 JSON。

更新前先“停止服务并准备更新”，成功后退出并替换 App。已有旧仓库与旧 JSON 不会自动删除，按旧版兼容入口恢复。

## 开发接口

图形 App 是日常入口。CLI 管理命令从标准输入读取请求，口令不可写入 shell 历史、命令参数或仓库。`srics manager info|configure|start|stop --config /absolute/config.json` 管理部署；新版备份接口为 `unified-key-status|generate|confirm` 和 `unified-backup-configure|run`。网页不开放密码创建或重设接口。

`configure` 请求含 `config`、当前 / 新登录密码、当前 / 新保险库口令及闲置锁定时间。配置结构中的旧 `backupRepository`、`backupPasswordFile` 和 `cloud` 为兼容字段，新备份使用 `unified`，不能把旧版手工设置当作新部署步骤。

检查命令和构建规则见 [README](../README.md)、[版本维护](VERSIONING.md) 与 [构建工作流](BUILD_WORKFLOW.md)。历史实现细节见 [旧版部署记录](M5_DEPLOYMENT.md)；其中当时的限制不代表当前版本。
