# M5 部署配置：局域网 HTTPS 与每日备份

2026-09-20。本次增量已实现可配置的局域网 HTTPS 和本地 / 独立硬盘每日加密备份；M5 整体验收仍未完成。

## 本机程序

停止服务后，在“访问范围”选择本机的私有 IP；默认仍为“仅本机”。保存并启动后只监听所选 IP 和端口，使用 HTTPS，不开放 HTTP 降级端口，也不修改路由器或防火墙。地址不在本机或端口占用时启动失败。建议在路由器上固定主机 IP。

程序生成每次安装独立的本地 CA（10 年）与服务端证书（1 年）。保存 / 启动时，如果 IP 改变或服务端证书剩余不足 30 天，签发新服务端证书并保留 CA。持续运行超过证书有效期前需重启以续期。根证书损坏、丢失或临近到期不会静默替换，需要单独处理证书及设备信任。

“导出 HTTPS 公共证书…”仅导出 `SRICS-Local-CA.cer`，并显示 SHA-256 指纹。将其传到自己要访问的设备，核对指纹并在系统中安装、信任后再打开 HTTPS 地址；本机浏览器也需要信任。应用不自动添加系统信任，不跳过浏览器证书警告。各平台证书安装方式及真实跨设备访问仍需验收。

CA 和服务端私钥放在配置目录的 `https/` 下，目录权限 700，密钥权限 600；公共导出文件不含私钥。CA 限制服务端认证用途，加入 localhost 与私有 / 回环 IP 的名称约束。此 CA 应只安装到自己管理的访问设备，不能分享 `authority.pem` 或 `server.pem`。这些运行密钥不属于资料库快照；恢复到新主机时可以重新建立 HTTPS 信任，资料解密仍依赖独立保险库和备份口令。

TLS 最低 1.3；服务端按真实连接校验 HTTPS Origin、Host 与 CSRF，不信任转发头来修改来源。会话 Cookie 使用 Secure、HttpOnly、SameSite=Strict。后台就绪检查使用本次安装的 CA 正常校验证书，不关闭验证。

## 每日加密备份

在本机程序中选择备份目录、独立口令文件，开启“每天自动备份”并填写 `HH:mm`（默认 03:00）。使用主机当前时区，服务运行时每 30 秒检查一次；睡眠或关机错过的任务在恢复运行后合并补做一次。后台服务尚不注册登录 / 开机自启，重启电脑后仍需打开程序启动。

失败或中断后至少等待一小时再自动重试，手动“立即备份”仍可随时触发。手动和自动任务共用互斥锁，不能重叠。只有数据库一致性快照、对象校验、restic 写入和全部备份数据读取检查均成功，并且状态写入成功后，才显示成功。失败保留上次成功快照的信息。

配置不同备份目录后，以目标路径散列区分状态，不能沿用另一目标的成功记录。首次仓库只在目标为空、父目录存在时初始化；已初始化仓库缺失时拒绝重新创建。首次配置独立硬盘时应选择该盘内的专用备份子目录。私密内容连同加密元数据与密钥包装一起备份，任务不需要保险库解锁。

网页备份中心显示自动时间、主机时区、下次执行 / 重试时间、最近尝试和最近成功的快照。备份运行时刷新状态；页面关闭不影响服务端任务。当前不自动清除历史快照；保留策略和容量管理待下一批实现。

## 验证与剩余事项

新增自动测试：信任正确 CA 的真实 TLS 连接、错误 CA / 错误 IP 拒绝、IP 改变保留 CA、根密钥丢失拒绝替换、HTTPS 登录 Cookie 与 CSRF、HTTPS Origin / Host 边界、夏令时日程、失败重试、丢失备份盘 / 仓库不重建、切换目标状态隔离，以及定时触发真实 restic 备份并恢复校验。

测试仅使用合成资料，既有演示保持本机访问。仍待完成：云服务商与凭据接入、历史快照保留策略、真实独立硬盘与另一设备恢复演练、跨设备 HTTPS 信任验收、Apple 公证与多机兼容，以及前期记录的上传分块恢复和回收站自动清理。上述增量不代表可以跳过完整发布验收。

实现参考：[Go x509](https://pkg.go.dev/crypto/x509)、[Go TLS](https://pkg.go.dev/crypto/tls)。
