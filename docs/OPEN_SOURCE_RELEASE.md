# 开源发布记录

准备版本：v0.3.0-rc19 · Build 25，2026-10-03。项目许可为 AGPL-3.0-only；公开测试版不代表公网、多租户、其他系统或真实云账号已经验收。

## 随代码与程序提供

- 根目录 LICENSE、NOTICE、第三方声明及 Feather 图标许可。
- CONTRIBUTING、SECURITY、问题表单和 PR 模板；不要求额外 CLA。
- 登录页、关于页与 App 的源码、许可证和版权入口。
- 每次构建的受控源码包、文件校验值、提交与修改状态；构建后变化会阻止打包。
- Go、Vue、固定 restic、随包图片工具和动态库的实际许可全文。

源码包收录项目代码、文档、图标、合成测试样本和构建脚本；不收录 `.git`、资料目录、应用配置、备份、恢复 JSON、未跟踪私人文件或旧构建。拒绝受管理的敏感文件名与符号链接。从源码包重建需要按锁定版本下载构建工具和依赖，不包含用户资料。

## 对外发布步骤

1. 在干净提交上构建并检查源码与版本一致；公开内容仅含源码、文档和合成样本。
2. 将验收的 `develop` 快进到 `main`，通过 GitHub Desktop 推送，不触发 Actions。
3. 仓库公开时启用 GitHub 私密漏洞报告，检查 README、Issues 与许可证页面。不要把公开 Issue 作为漏洞披露渠道。
4. 若发布 App 下载，使用维护者的 Developer ID Application 证书签名并提交 Apple 公证，复核程序中保留源码和第三方许可；签名凭据不进入仓库。当前构建机未安装该证书，临时签名包应明确标为本机试用。
5. 发布测试版本及变更说明，注明 Apple Silicon、macOS 27+ 与实际验证范围；在目标设备和独立备份位置完成恢复验收后再考虑正式版本。

GitHub Actions 仍仅手动触发。云端工作流执行源码及服务检查；没有为开源准备消耗 GitHub 编译额度，当前完整 App 打包在本机执行。
