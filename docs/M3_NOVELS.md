# M3 小说章节、编辑与阅读

> 0.3.0-rc1 更新：分块续传、清理策略、本机自启、更新前保护和恢复副本的单项取回已接入。本文保留阶段记录；当前范围以 [收尾记录](RELEASE_READINESS.md) 和 [验收清单](ACCEPTANCE.md) 为准。

日期：2026-09-20。沿用现有 Global 界面。小说与漫画、图片保持独立的数据范围；测试使用合成内容。

- 新建小说、修改名称和标签，名称包含搜索（拉丁字符忽略大小写），多标签 AND 筛选，列表每页 40 本。
- 小说目录与正文分栏。新增章节、纯文本编辑、上移 / 下移排序；整本小说进入公共回收站，章节在本书的“已删除”目录恢复。删除保留正文、位置及历史版本。
- 默认进入阅读模式，目录与上一章 / 下一章切换，记住最后阅读的章节，字号 14–28px；沿用全站深浅色偏好。正文作为文本展示，不执行 HTML。
- 编辑器停止输入 1.5 秒后自动保存，也可点击保存或使用 Command / Ctrl + S。成功状态只依据服务端响应；输入法组合期间不触发自动保存。每章正文上限 512 KiB UTF-8，每本上限 3000 章（含已删除章节）。
- 保存使用章节修订号；名称 / 标签及目录排序使用小说修订号。过期的编辑、排序或版本恢复返回冲突，不能覆盖新内容；丢失响应后的同内容保存可以安全重试。
- 保存失败保留页面中的草稿并暂停自动重试，可手动保存或下载草稿。冲突时展示服务器正文供对照，替换草稿前明确确认；不会提供绕过修订检查的强制覆盖。登录失效时可在编辑器中重新登录，保留未保存正文。
- 切换章节、模块、退出登录，以及关闭 / 刷新页面时保护未保存修改。草稿不写入浏览器持久化存储；确认放弃或关闭页面后不会保留本地草稿副本。
- 每章保留最近 20 个历史检查点。手动保存前保留原状态；五分钟内的连续自动保存合并为一个检查点，保留这一轮开始前的状态。恢复历史版本也先保留当前正文，并检查当前修订号。
- 按目录顺序导出 UTF-8 TXT，不含已删除章节。导出逐章写入临时文件，完成一致性拷贝后释放数据库锁再传输，下载结束清理临时文件。
- 正文、名称、标签、顺序、已删除章节、历史版本与阅读章节同存 SQLite，纳入现有一致性快照和 restic 加密备份。旧数据 schema v1 升级前生成权限 0600 的数据库快照，保存在资料目录的 staging/before-novels-*.db，再事务迁移到 schema v2。旧版本程序拒绝打开较新的 schema。

验证覆盖：并发编辑唯一胜出、修订冲突、丢失响应重试、自动保存历史合并、20 个历史上限、空间不足时保持旧内容、章节与小说删除恢复、跨小说隔离、排序冲突、名称标签组合查询、接口鉴权与 CSRF、纯文本导出、迁移前快照，以及移除源库后从 restic 独立恢复正文 / 历史 / 阅读位置 / 已删除章节。

当前仍为本机开发版；私密保险库、局域网 HTTPS、回收站自动清理、云端自动备份与发布验收继续按后续阶段实施。

浏览器验收：新建小说与章节、自动 / 手动保存、排序、冲突时保留草稿、取消离开、断线失败提示、服务重启后的原地重新登录并继续保存、历史版本回退、章节删除恢复、阅读与字号切换均通过。390px 手机视口检查无横向溢出，深浅色阅读正常。会话保护另有 4 项前端回归测试，覆盖普通登录失效、后台轮询、保存接口 401 和断网。
