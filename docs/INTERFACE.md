# 界面与交互约定

视觉以 **Lumoswitch Global 版**为参考。依据本地项目的 `apps/web/app/_landing/global/global-landing.css`、Global 登录组件样式以及 `_console/workspace.css` 的控制台组件：黑白对比、较粗的字重、胶囊按钮、圆形控件和明确描边。不采用 CN 版的蓝色宣传区或营销版式；语言切换不等于部署版本切换。

保持 SRICS 的名称、资料分类和中文内容，不引入外部字体、图片或新的界面依赖。

2026-09-23 照片卡片整理：图片和个人照片取消固定底栏，卡片由照片填满。文件大小、备份状态和下载入口改为叠在照片底部的透明渐变浮层，仅桌面悬停或键盘聚焦时显示；浮层文字不阻挡点击照片，触屏仍通过大图查看与下载。

2026-09-23 操作整理：普通图片和个人照片的勾选框、下载入口在悬停或键盘聚焦时显示；顶部“选择图片”进入批量操作，点整张图片即可勾选。普通与私密资料均支持选择已加载项、清空选择，单次最多 100 项并明确提示。普通与私密照片的大图支持左右按钮及方向键切换，抵达已加载末尾时继续读取下一批；计数使用总数量。加载期间关闭预览、切换照片或锁定保险库后，迟到的请求不会重新打开或替换预览。

验证：18 项前端测试通过（含跨分页切图、并发按键、关闭 / 锁定后迟到响应与失败重试），前端及 Go 构建、Swift 类型检查和 macOS 打包通过。在运行程序中实测整图勾选、选择已加载项、清空与退出选择、普通及私密照片的按钮 / 方向键切换、Esc 关闭以及锁定关闭预览；跨分页行为使用自动化测试覆盖，现有演示资料未达到分页数量。

2026-09-22 细节整理：登录标题使用独立横向布局，图标与文字固定间距、垂直居中；不叠加页面标题的装饰下划线。图片、个人照片和私密照片的选择控件仅保留勾选框，透明点击区域不绘制黑底或外圈，选中不再给整个卡片加描边。私密照片选中后勾选框持续可见，操作按钮仍按原有悬停 / 选择模式显示；键盘焦点提示保留。

2026-09-23 本机程序：SwiftUI 启动与配置窗口沿用 Global 的黑白配色、胶囊导航和按钮、圆角描边卡片。左侧分为服务配置、密码与保险库、备份设置、空间管理、版本与更新；右侧独立滚动，底部保留保存、启动 / 停止和恢复入口。恢复历史与单项取回窗口共用颜色、输入框、标题和按钮组件，配色跟随 macOS 深浅色。保留原有服务、凭据和备份行为，未引入 WebView 或新的运行依赖。

## 视觉与信息结构

- 资料库是默认首页。标题下集中呈现真实恢复验证状态，六类资料卡片使用统一的单色线性图标；状态颜色只用于成功、失败和连接信息。
- 顶部品牌栏、独立的工作区侧栏、胶囊形选中项与黑白主按钮。卡片使用 2px 描边、20–24px 圆角和轻量阴影，标题下使用少量青色点缀。
- 浅色使用 `#f1f3f7` 页面背景、白色面板与 `#050505` 强调色；深色使用 `#0a0a0c` 背景、`#121317` 面板与白色强调色，与 Global 共用设计变量对应。
- 初次访问跟随系统主题，右上角可切换浅色 / 深色。仅主题偏好保存在浏览器，刷新后保持；存储被禁用时当前访问仍可切换。
- 桌面侧边栏区分收藏、私密空间和工具；720px 以下改为“资料库 / 恢复验证 / 关于”三项带文字的底部导航，预留底部安全区。
- 产品入口不展示开发编号。M0–M5、技术环境等放在“关于此版本”或可展开的次要信息中。
- M0 的业务入口明确显示“准备中”，进入后说明开放范围和计划。没有上传按钮、虚构文件数量或已备份承诺。

## 导航与反馈

- 使用原生链接和 hash 路由，支持直接访问模块、页面刷新、浏览器前进后退；不增加路由依赖或服务端通配路由。未知地址显示返回资料库入口。
- 页面切换更新标题，将焦点移到主要内容并回到顶部。提供键盘跳过导航按钮、可见焦点、明确的当前页标识。
- 验证分为等待、启动、运行、通过、失败和连接中断状态。启动按钮防重复；服务端返回 409 时接入已有任务。
- 验证在本机继续运行，切换页面不会停止；首页和导航显示运行状态。已完成报告可下载，失败项默认展开，其余详情按需查看。
- 状态请求有超时，同一时间只保留一个读请求；发起新验证前等待旧请求结束，避免旧结果覆盖新任务。隐藏页面减少刷新频率，重新显示时同步。
- 断线显示全局提示与重新连接按钮，保留最近一次结果；连接恢复后同步服务器状态。服务重启清空报告是 M0 已有行为，页面有说明。
- 状态同时使用文字和图标，避免只依赖颜色。遵循减少动态效果偏好，关闭旋转与过渡。

## 后续功能遵循

业务功能开放后将“准备中”替换为真实空状态和主要操作。筛选、批量操作等只出现在需要它们的模块中；列表和阅读内容优先，技术信息继续按需展开。

本轮不改变加密格式、存储、备份或局域网访问边界，也不修改 Lumoswitch 项目。

## 2026-09-19：接入首批实际功能

沿用 Global 版已确认的样式与菜单内边距，首次进入增加设置登录密码 / 登录页面。首页改为服务端真实收藏数量与原件大小，不再把合成恢复验证当成主入口。漫画、图片、个人照片进入实际资料页；备份中心、回收站和样本验证分别呈现。

漫画以封面卡片展示；名称搜索和多标签筛选位于列表上方，导入前可查看文件页序、显式排除不支持输入。阅读仅保留连续滚动，页图无间距衔接；右下角悬浮页码随滚动更新，并可输入页码跳转。页码输入框的灰色描边常驻，聚焦时只变为蓝色，尺寸和位置不变。手机页码位于底部导航上方。图片提供列表 / 随机切换、选择后批量工具条及原图弹窗；个人照片保留简单网格，不增加名称或搜索字段。

上传、编辑使用原生 dialog 提供焦点约束，状态只在服务器确认后更新。未完成上传保留在原模块的任务栏，重新选择来源可重试。手机延用资料库 / 备份 / 回收站底栏；登录与资料页共用深浅色偏好。当前功能及限制详见 [第一批功能记录](M1_M2_LIBRARY.md)。

## 本机配置与文案调整（2026-09-19）

- 移除欢迎语、宣传语和空状态情绪文案，仅保留名称、状态和操作说明。已确认的 Global 风格及侧栏选中位置保持。
- 网页仅登录，不承担首次密码设置。未配置时显示本机程序入口说明。
- 独立 macOS 窗口负责资料目录、端口、登录密码与备份配置、后台启动和停止。运行时锁定配置表单；关闭窗口不会结束服务。

## 小说编辑与阅读（2026-09-20）

小说列表沿用描边卡片、名称搜索和标签筛选。桌面目录与正文分栏，手机改为上下布局；编辑和阅读分开，保存状态、近期版本与章节恢复均在本书内呈现。未保存内容使用页面内对话框确认离开；登录失效可原地重新登录，后台连接检查不卸载有草稿的编辑器。


## 私密照片以浏览为主（2026-09-20）

照片墙默认只保留图片，不为下载/删除留固定底栏。桌面悬停在当前照片上、或键盘焦点进入卡片时显示操作；顶部“选择”进入批量选择，点图片即可勾选，“完成”清空选择并回到浏览。触屏默认点击照片看原图，原图工具栏提供下载与删除，批量选择通过顶部入口完成，不依赖悬停。选择状态不持久保存，切换列表或锁定后清空。

## macOS 应用图标（2026-09-29）

应用图标改为 Apple 原生风格的简洁屏幕：浅色玻璃底、白色机身与蓝色屏幕。使用 Icon Composer 27 保存两层 SVG 与玻璃参数，打包时由 actool 编译 Assets.car 和 ICNS，保留系统深浅色与着色外观；Finder、Dock 和配置窗口共用。源文件与导出方式见 [AppIcon 说明](../desktop/Assets/README.md)。网页和配置界面的 Global 布局保持原有约定。

默认直接交付 `.app` 并在 Finder 中选中，不生成 ZIP。旧程序运行时可用 `SRICS_APP_OUTPUT` 指定新的绝对 `.app` 输出路径，避免替换运行中的包。新版图标在退出旧程序并启动新包后生效。
