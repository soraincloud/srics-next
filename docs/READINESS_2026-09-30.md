# 2026-09-30 投入使用检查

检查分支：`develop`，基于 `bb878b3` 加本轮文案与标签回归检查。应用为 `0.3.0-rc6` / build 11，Apple Silicon，最低 macOS 27.0。全程本机构建，未运行 GitHub Actions。

## 结论与实际配置

本轮功能、并发、集成、依赖检查与随包样本恢复全部通过，可以开始保留原始副本的日常使用。没有发现必须补写才能使用的标签功能；清理了过时开发文案。检查通过不代表零漏洞，也不代表最终云账号、100 GB 资料量和故障设备场景已验收。

只读核对本机当前配置：云备份未启用，局域网 HTTPS 未启用；本地备份已配置，但与资料位于同一文件系统；每日备份时间为 03:00，登录自启与异常重启均关闭。本轮没有修改这些设置，没有读取或输出真实口令，也没有启停日常资料库。此处状态仅描述当前电脑，不代表未来独立 Mac 的配置。

正式作为唯一资料源前，仍须在目标 Mac 完成以下部署验收：

1. 配置独立云端目标，完成真实备份与完整校验；确认定时任务实际执行及失败状态可见。
2. 为该备份目标生成恢复 JSON，重新选取验证，完成覆盖恢复密钥及私密区的新备份；将 JSON 独立保存在该 Mac 之外，同时保留云账号的访问与找回方式。
3. 在空白环境仅凭完整备份仓库与恢复 JSON 恢复，逐类取回普通和私密原件并核对。通过前保留原始副本。恢复密钥不能补回未备份或已损坏的数据。
4. 设置正式登录与保险库口令；按需开启自启、异常重启，并验证实际重启后的运行。局域网访问时，在访问设备上完成证书信任与 HTTPS 实测。
5. 确认目标设备和云端容量、上传临时空间、恢复副本空间；100 GB 真实规模、断电和拔盘仍需设备验收。部署清单见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 标签与文案

- 漫画：上传时设置名称和标签，列表编辑名称 / 标签；名称搜索、单标签与多标签筛选可组合使用。
- 小说：新建与编辑标签，名称搜索与多标签筛选。多个标签为 AND，必须全部满足；逗号或中文逗号分隔，保存时去除首尾空白与重复项。
- 图片、个人照片、私密照片按原定范围不增加标签 / 名称搜索；个人文件保留名称搜索。
- 清理 RC1、验收版、首页开发计划链接、关于页阶段表，以及已不可达的“功能开发中”页面。
- 样本恢复入口统一为“样本自检”，明确临时样本不能代表真实资料已备份；真实备份状态仍在备份中心。
