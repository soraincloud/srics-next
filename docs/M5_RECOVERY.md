# M5 备份历史与本机恢复

2026-09-20，实施记录。本批补齐历史快照浏览、本机恢复及恢复后的资料库切换；历史快照保留与回收站自动清理仍为后续任务。

## 使用流程

- 网页备份中心按本地 / 云端查看历史备份，显示时间、快照编号和备份文件规模。历史列表只读取当前目标的 SRICS 资料库快照；不把样本验证快照或存在快照本身当作校验成功。
- 本机窗口提供独立“从备份恢复”入口。连接设置可从当前配置带入，也可单独填写，适用于原资料盘缺失或新电脑；不会先初始化资料库或要求创建新密码。
- 读取历史快照、选择一个恢复点、选择存放位置后，在其下新建恢复目录。拒绝覆盖已有目录，也拒绝在当前资料库、备份仓库或程序配置目录中恢复。
- 恢复执行 restic 数据验证、SQLite 完整性与对象哈希检查，成功后在恢复目录写入 `.srics-recovery.json`。私密内容保持密文，独立保险库口令仍需在实际使用时验证。
- 校验完成后可单独选择“停止服务并启用”。窗口会先停止服务，再复核目标；仅切换本机配置中的资料目录，保留原资料和备份，使用备份时的登录密码及保险库口令。
- 关闭窗口后，可通过“打开恢复目录…”重新校验和启用已有恢复目录，不需要重复下载。
- 失败或中断不会自动删除已恢复的部分文件；保留目录供检查，重新尝试需使用新目录。云端恢复可能产生下载流量费用。
