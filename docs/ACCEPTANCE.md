# SRICS Next 部署验收清单

更新于 2026-10-14。当前交付为 v0.3.0-rc30 / Build 36，包含照片原件保留、实况照片和安全修复。请在实际部署设备上按下面清单验收，版本以程序窗口和网页“关于 SRICS”显示为准。

自动化检查记录见 [整体检查](OVERALL_CHECK_2026-10-14.md)；后续变化见 [更新记录](../CHANGELOG.md)。下面的勾选留给使用者在最终部署设备和实际账号上确认。

## 首次打开

- [ ] 双击本次交付的 `SRICS Next.app`，选择资料目录，设置登录密码和独立保险库口令；所有密码均可显示后核对，错误出现在对应字段旁。
- [ ] 启动服务后用刚设置的登录密码进入网页；关闭配置窗口后后台服务仍运行。
- [ ] 首次配置无需额外安装 Go、Node、图片编码器或备份工具。正式使用前更换演示口令；未启用局域网 HTTPS 时，本机访问无需安装证书。
- [ ] 默认自动清理、登录自启和崩溃重启均关闭；按实际需要在服务停止后配置。

## 八类资料

- [ ] 漫画：导入 `漫画目录/00001.webp、00002.webp…`；修改名称、设置标签、按名称和标签搜索。封面、无缝连续阅读、页码定位和整本 ZIP 下载正常。批量导入选择各本漫画的共同上级目录。
- [ ] 小说：名称与标签搜索；新建、编辑、排序、删除、恢复章节及历史版本。已完结 / 未完结颜色、开关和筛选正确。离开阅读页再打开，点击“继续阅读”回到原章节与段落；编辑模式不覆盖阅读记录。
- [ ] 文档：创建具名 Markdown，设置标签、组合搜索、编辑、解析预览、阅读和下载 MD。未保存离开可取消；版本冲突或登录过期时草稿保留，可下载草稿后处理。
- [ ] 图片：列表、随机墙、大图、单张及批量下载。普通静态支持格式无损转 WebP，已有 WebP 和 GIF 原字节保留，GIF 全帧动画正常。新上传统一 IMG 连续编号，重复请求与续传不重复编号。
- [ ] 个人照片：原件字节与元数据保留，列表、大图及下载正常；HEIC 等格式用独立预览。实况照片同时选同名照片和 MOV，合并一条，可切换静态 / 动态，下载容器包含两份原件。
- [ ] 文件：普通文件无需解锁保险库，可上传、改名、按名称搜索、下载、删除与恢复；空文件也能保存。
- [ ] 私密照片：独立口令解锁、列表、随机墙、大图与下载。HEIC 和实况照片可预览；锁定后预览、名称、视频和上传队列消失。
- [ ] 个人文件：保险库中的加密文件，可批量上传、改名、按名称搜索、下载、删除与恢复；未解锁不能读取内容。

## 上传和回收站

- [ ] 较大文件暂停后继续；刷新、锁定或重启服务后重新选择同一原文件，已保存的分块不重传。同名同大小但内容不同的来源会拒绝。
- [ ] 实况照片续传使用“选择照片与视频继续”，同时重新选择原照片和 MOV。缺少或重复配对候选会明确报错。
- [ ] 私密任务名称、内容哈希和分块加密保存。浏览器重开后需要重新授权选择原文件。
- [ ] 回收站可恢复；彻底删除有确认，取消不会删除。私密回收站需解锁，小说章节回收站独立操作。
- [ ] 自动清理默认关闭；启用后普通回收站启动时及每小时处理，私密回收站在解锁读取列表时处理。历史备份按独立规则保存。

## 一种备份和一份恢复 JSON

- [ ] 在 App 备份设置中保存恢复 JSON，重新选择该文件验证，再选择备份位置并创建第一份 `.sricsbackup`。
- [ ] 之后网页立即备份、App 另存、每日自动备份和更新前保护使用同一套备份流程，无需再次输入备份口令或选择 JSON。
- [ ] 位置可为本地目录、独立硬盘、网盘同步目录或 S3。保留多个日期版本，失败不覆盖已成功备份。网盘同步目录需另外确认同步已经完成。
- [ ] 首次启用私密区、修改登录密码或保险库口令后，同一 JSON 与新的完整备份仍能恢复；修改日常口令必须验证旧口令。
- [ ] 在另一目录或另一台 Mac，仅用一份完整备份文件和匹配 JSON 恢复，核对数据库、全部八类资料、标签、章节、阅读状态、私密名称与原件。
- [ ] 恢复默认写入新目录，原资料库保留。可以单独取回文件，或为恢复副本设置新密码后停止服务并启用。
- [ ] 错误 JSON、损坏或下载不完整的包、已有目标目录、离线磁盘、云端上传或读回失败均明确报错，不显示成功。
- [ ] JSON 单独保存在资料库设备之外，与云端备份分开保管；如果直接从云端取备份，还要保留云账号的访问与找回方式。

旧仓库、旧 JSON 和旧包仍通过兼容入口恢复。旧格式说明见 [历史恢复密钥说明](RECOVERY_KEY_LEGACY.md)，不用于新资料库的日常设置。自检报告 JSON 只用于排查问题，不是恢复钥匙。

## 迁移、更新和运行

- [ ] App“迁移资料目录”选择新的磁盘位置，完成后当前路径更新，旧资料目录仍保留。
- [ ] 新位置可用原密码登录、原口令解锁；检查正文、历史版本、回收站、原件与未完成上传，再做一次独立备份。
- [ ] 换设备时先从最终备份恢复到新 Mac，重新配置备份和 HTTPS；验收完成前保留旧机资料。
- [ ] 登录自启、崩溃重启按需开启；实际注销或重启验证。手动停止不会自动重启。
- [ ] 更新前点击“停止服务并准备更新”，等待加密备份和读取校验通过，保留旧 App、配置与记录，再退出窗口并替换 App。
- [ ] 更新失败保留旧程序与原目录。发生资料库结构升级后，旧程序需使用升级前备份恢复到新目录，不能直接打开新版资料库。
- [ ] 局域网 HTTPS 在实际访问设备安装并信任导出的公共证书后可用；IP 变更后重新配置。私钥不分发给访问设备。

## 实际设备验收范围

以下自动化合成测试不能代替：

- [ ] 自有 S3 账号或独立硬盘完成真实备份，再在另一台设备完整恢复并解锁。
- [ ] OneDrive 等同步软件上传完成后的独立下载与恢复。
- [ ] macOS 输入法与 Safari 实际逐键输入、显示隐藏切换及密码保存登录。
- [ ] 实际 Live Photo 的音视频播放，以及原件重新导入 Apple 照片应用后的识别。
- [ ] 外置资料盘拔出、重新连接、断电和磁盘损坏后的恢复。
- [ ] 约 100 GB 真实资料规模和大量私密条目的性能、空间与备份用时。
- [ ] Developer ID 签名、公证及其他系统 / CPU 架构分发；当前本机构建仍为 Apple Silicon、临时签名。

当前上限：图片和漫画单张原件 64 MiB，实况照片两部分连容器合计 64 MiB；普通与私密文件单文件 10 GiB。静态图片和预览最多 1 亿像素，WebP 单边最多 16383 像素，GIF 全帧合计最多 4 亿像素。临时分块、合并原件、内部缓存和完整备份可能同时占空间，需保留足够磁盘余量。自动清理不等于磁盘安全擦除。
