# SRICS Next 部署验收清单

更新于 2026-10-03，当前应用为 v0.3.0-rc20 / Build 26。七类资料与备份使用已有界面，配置统一放在本机 SRICS Next 程序。此清单中的勾选由使用者在最终部署设备上验收后填写；功能检查见 [投入使用检查](READINESS_2026-09-30.md)，后续变化见 [更新记录](../CHANGELOG.md)。

## 打开程序

双击本次交付的 `dist/0.3.0-rc18-build23/SRICS Next.app`，点击“启动服务”或“打开资料库”。程序包自带服务、网页、图片编码器和 restic，无需另外安装运行环境。同一系统用户会沿用已有配置和口令；正式使用前更换演示口令。关闭配置窗口不停止后台服务。默认自动清理、登录自启和崩溃重启均关闭，按需在服务停止后配置。

## 日常功能

- [ ] 漫画：导入 `漫画名称/00001.webp、00002.webp…`；修改名称、设置标签，分别按名称和标签找回；第一页封面、无缝连续阅读、页码定位、整本 ZIP 下载正常。
- [ ] 批量漫画：勾选批量导入，选择 `总目录/漫画一/图片、总目录/漫画二/图片…`，每本可单独改名，标签共用。PNG/JPEG 等支持格式经像素无损校验转换为 WebP，已有 WebP 保留。
- [ ] 小说：新建、命名、标签、搜索；绿色“已完结” / 橙色“未完结”开关保存后列表同步，状态筛选可与名称、标签搜索组合使用，分页与数量准确；章节新增、编辑、排序、删除与恢复，修订恢复可用。滚动后离开再打开，点击角落“继续阅读”回到原章节与段落；编辑模式不覆盖阅读位置。两个页面同时编辑时提示冲突。
- [ ] 图片：批量上传 JPEG / PNG / WebP / GIF；JPEG / PNG 无损转 WebP，WebP / GIF 字节不变。GIF 与 WebP 在网格、随机墙和大图混合展示，GIF 动画正常播放；单张和选择后打包下载。新上传使用 IMG-000001 等连续编号，扩展名匹配真实格式，不保留来源文件名；暂停 / 重启后重新选源图片仍可核对内容并续传，重试不重复编号。默认照片卡片不常驻管理按钮。
- [ ] 个人照片：原件上传、列表、大图或文件占位、下载。保留原始字节和元数据。
- [ ] 私密照片：独立口令解锁，列表、随机墙、大图与下载；锁定后预览、文件名称和上传队列消失。
- [ ] 个人文件：批量上传、重命名、按名称搜索、下载与删除。整个模块默认加密。

## 上传与容量

- [ ] 上传较大测试文件，暂停后继续；刷新或重启服务后，重新选择同一个原文件，已保存分块不会重传。替换同名同大小但内容不同的文件会拒绝。
- [ ] 私密队列在逐项核对源文件后保存，全部登记后开始传内容；任务名称与分块均加密。核对尚未完成的任务未确认保存，刷新需重新添加。浏览器不会保存来源文件权限，重开后需要重新选择。
- [ ] 回收站可恢复；“彻底删除”有明确确认，取消不会删除。私密回收站需解锁，小说章节回收站独立操作。
- [ ] 如需自动清理，停止服务，在本机程序启用并设置天数；普通回收站启动时和每小时处理，私密回收站在解锁后读取列表时处理。未启用则永久保留。

## 备份与恢复

- [ ] 备份中心选择本地或云端，立即备份后看到完整数据检查成功、时间和快照编号。刷新历史列表可找到该恢复点。
- [ ] 在本机程序启用每日备份，确认时间与网页显示一致。停机错过时间后补做，失败每小时重试。
- [ ] 若启用保留策略，设置每日 / 月度数量后，在网页“预览清理”核对将删除的恢复点。按 UTC 日和月分组各保留最新一个，取并集，始终保留最新快照；新备份完整检查成功后自动清理。默认保留全部。
- [ ] 本机程序“从备份恢复”：选择恢复点、新目录，等待文件校验通过；原资料库不被覆盖。
- [ ] 恢复结果中“取回单项文件”：普通目录可直接读；输入备份时的保险库口令后显示私密目录。导出漫画 ZIP、小说 TXT 或一个原件，保存到独立目录，不切换当前资料库。当前需先恢复整份副本，尚不支持直接从云端只下载某一项。
- [ ] 若需整库恢复，再点击“停止服务并启用”，重启后使用备份时的登录密码和保险库口令。保留旧资料目录。
- [ ] 生成恢复 JSON，重新选取验证并完成覆盖该密钥的新备份。将 JSON 单独保存在资料库设备之外。在空白环境仅凭一份完整 .sricsbackup 文件及该 JSON 应急恢复，验证普通原件与私密原件均可取回；如直接从云端下载，还需保留云账号的访问与找回方式。

## 本机运行与更新

- [ ] 开启“登录电脑后自动启动”，保存后重新登录电脑验证。开启“异常退出后自动重启”，异常退出会延迟重启；手动停止不会重启。
- [ ] 更新前点击“停止服务并准备更新”，等待加密备份和完整读取检查通过。打开的目录包含旧 `.app`、配置和 `update.json`。退出窗口后手动替换 `.app`，再打开启动。可取消准备任务；取消后需自行重新启动服务。
- [ ] 更新失败时保留旧程序和原目录。若已发生数据库升级，使用旧程序恢复升级前快照到新目录再启用；不要让旧程序直接打开已升级的资料库。

## 实际部署验收

以下需要实际设备或账号，未以合成测试代替：

- [ ] 实际局域网设备安装并信任公共证书后访问，确认仅选定局域网入口可用。
- [ ] 自有云端目标或独立硬盘完成真实备份，再在另一台设备完整恢复并解锁。
- [ ] 登录自启的实际注销 / 重启，外置资料盘拔出与重新连接、断电恢复。
- [ ] 100 GB 真实资料规模、较多私密条目的性能与剩余空间。分块临时文件与合并原件可能同时占空间，备份仓库也需独立余量。
- [ ] Apple 签名、公证和其他 macOS / CPU 架构分发。本次是 Apple Silicon 本机构建、临时签名包。

当前限制：照片与漫画单张原件最多 64 MiB，私密个人文件最多 10 GiB；图片预览最多 4000 万像素。自动清理不等于磁盘安全擦除，历史备份按独立策略保存。已有旧版本迁移索引保留在 `staging` 供回退分析，更新前恢复点保留在加密备份文件。


## 资料迁移验收

- [ ] 服务配置 → 迁移资料目录，选新磁盘位置，完成后当前路径变为新目录，旧目录仍存在。
- [ ] 新位置能使用原密码登录、原口令解锁；检查漫画、照片、小说正文与历史版本、私密文件、回收站及未完成上传。
- [ ] 迁移后完成一次独立备份，用保管的恢复 JSON 验证恢复。
- [ ] 换设备时，在新 Mac 上按安装说明从最终备份恢复并启用，重配备份与 HTTPS；验收完成前保留旧机数据。

## 日常密码与灾难恢复分离（Build 17）

- [ ] 本机“重设登录密码”只显示新登录密码与确认项，没有保险库开关或恢复 JSON 选择器。
- [ ] 保险库改密验证当前口令；旧口令错误时不保存，不改变私密资料。
- [ ] 恢复 JSON 只在备份管理、验证与独立备份恢复流程中使用，不用于日常密码管理。
- [ ] 使用完整备份与 JSON 恢复到新目录，取回私密原件并为恢复副本配置密码；当前原库不受影响。

- [ ] 私密照片与个人文件解锁框可通过眼睛按钮显示 / 隐藏口令，切换不会提交；提交解锁或离开窗口后恢复隐藏。

## 原生密码输入（Build 19）

- [ ] macOS 自带拼音已启用时，在隐藏框连续输入 ru 及长口令；显示后逐字核对，确认框填写相同内容后能正常保存。
- [ ] 输入中途切换眼睛按钮，光标与选区保留；粘贴中文、符号与首尾空格后内容不变。
- [ ] 完成真实键盘验收；自动化逐键验证不能替代所有输入法时序与实际输入速度。

## 旧版分步备份设置（Build 21，兼容）

- [ ] 独立硬盘 / 云端按钮分别打开正确的位置，未保存配置或服务运行时给出明确提示。
- [ ] 新建备份无需填写备份密码文件；向导创建并校验后才能进入应急恢复设置。
- [ ] 现有保险库口令只出现在恢复 JSON 生成步骤，导出后口令清空；重新选取 JSON 验证后才显示完成。
- [ ] 取消后可继续；连接旧仓库密码错误不覆盖原配置，掉线仓库不会自动重建。
- [ ] 云端使用真实账号完成一次向导，并在另一目录演练恢复普通与私密资料。

## 旧版手动加密备份包（Build 22，兼容）

- [ ] 完成本地备份向导与恢复 JSON 验证后，停止服务，打开“导出完整加密备份包”，选择匹配的 JSON 与新文件位置。
- [ ] 导出成功后 Finder 选中 `.sricsbackup`；实际上传到 OneDrive 并确认完成。JSON 另存离线，包内没有 JSON 的解密秘密。
- [ ] 在独立测试位置，仅用下载的包与 JSON 导入并恢复；验证七类资料、名称 / 标签 / 章节和私密原件，确认原 WebP 未变。
- [ ] 选择错 JSON、损坏 / 下载不完整的包、已有导入目录均明确失败，不覆盖或启用原资料库。
- [ ] 恢复副本可以单独取回文件，也能设置新的登录密码和保险库口令后启用。验收后可删除导入副本，原包与 JSON 长期保留。
- [ ] 实际资料量的导出 / 恢复时间、磁盘剩余容量和网盘容量足够。手动导出不等于之后新增资料自动上传，需要定期导出新包。


## 统一备份（Build 23）

- [ ] 首次保存与验证一份 JSON，再选位置并创建第一份 `.sricsbackup`；之后备份无需输入口令或选择 JSON。
- [ ] 本地、同步目录、S3、每天自动备份和更新前保护产出同一种完整文件。另存只写入所选位置。
- [ ] 同一份 JSON 在更换位置、修改密码及首次启用私密区后继续可恢复。
- [ ] 下载一份完整云端包，与 JSON 在新环境恢复，核对数据库、七类资料和私密原文件。
- [ ] 验证错误 JSON、包损坏、离线磁盘、上传失败和读回失败均不显示成功、不覆盖旧文件。
- [ ] 旧仓库、旧 JSON 与旧包仍可恢复，未被删除或改写。

## Markdown 文档

- [ ] 创建具名文档，设置多个标签，按名称和标签组合筛选。
- [ ] 编辑、预览、保存并阅读；下载 MD 后核对原文，删除后从回收站恢复。
- [ ] 未保存离开时可取消；同时编辑冲突时草稿保留；仅备份包和 JSON 恢复后能取回文档原文。
