# Markdown 文档模块

日期：2026-10-03。新增第七个资料模块“文档”，沿用资料库现有的厚边圆角、搜索框和标签筛选。

- 创建文档时填写名称、标签和 Markdown 正文；名称必填，标签可选。
- 列表按名称搜索，标签作为分类；多个标签与名称搜索同时筛选。
- 编辑、预览和阅读分开显示；预览解析当前草稿，阅读显示已保存正文。支持标题、列表、引用、代码、链接、表格等常用 Markdown。
- 正文以 UTF-8 `.md` 原文保存，可下载原文；不执行 HTML、脚本或代码块。外部图片按链接显示，避免阅读时自动访问第三方地址。
- 显式保存，支持 Command/Ctrl+S；未保存离开时确认，保存失败保留草稿，版本冲突不覆盖另一端修改。
- 删除进入现有回收站，可以恢复或彻底删除。
- 文档属于普通资料，登录后访问；敏感文件继续放入保险库。名称、标签和正文随现有统一 `.sricsbackup` 备份，可在恢复后下载 `.md` 原文。

实现复用不可变文件对象和 SQLite 索引：正文先原子写入对象，再提交名称、标签、文件引用和版本号。旧对象由现有回收机制管理，备份快照固定对应版本。空正文允许保存；单篇正文上限 512 KiB，名称和标签使用现有约束。

验收覆盖创建、编辑、联合搜索、Markdown 安全渲染、空正文、下载、回收站、并发修改、旧资料库升级、损坏文件拒绝读取，以及仅备份和恢复 JSON 的独立进程恢复。测试使用隔离合成资料。
