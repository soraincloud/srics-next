# SRICS Next 功能需求

版本：v1.0 · 更新日期：2026-09-19 · 状态：需求基线已确定；漫画、图片、个人照片和公共基础已接入，当前边界见 [第一批功能记录](M1_M2_LIBRARY.md)，底层验证见 [M0 开发记录](M0_FOUNDATION.md)。

本文件记录用户最新提出的六类内容及实施默认值，是当前功能范围的基准；先前概括性设计如有冲突，以本文件为准。单用户、局域网使用，短期原始文件规模不超过 100GB，继续以部署简单和可恢复为目标。

用户明确需要的业务入口为漫画、小说、图片、个人照片、个人私密照片、个人文件。备份中心和设置作为辅助入口，回收站与任务状态可作为公共面板。六类内容分别展示，底层复用上传、文件存储、缩略图、加密和备份能力。

**漫画按一个文件夹对应一本漫画处理。**

用户现有目录示例：

    1/
      00001.webp
      00002.webp
      00003.webp

| 编号 | 功能 | 行为与验收 |
| --- | --- | --- |
| C01 | 文件夹上传 | 选择或拖入一个漫画目录；批量选择多个同级目录时，每个目录分别建一本。上传前展示识别结果、页数和顺序。ZIP 不是必需上传格式。 |
| C02 | 漫画名称 | 名称必填，默认取目录名，例如 1；可改成实际书名。页面展示和名称搜索均使用这个名称，不依赖存储目录或图片文件名。允许同名书籍，按独立编号区分。 |
| C03 | 页序 | 按文件名自然数字顺序排列，例如 1、2、10；00001.webp 先于 00002.webp。编号缺口保留，不伪造缺页。相同排序结果采用稳定的文件名比较作为次序。 |
| C04 | 列表与首页预览 | 每本显示名称、标签、页数和第一张有效页面的预览图；此处“首页预览”指漫画第一页。分页或增量加载。 |
| C05 | 标签与搜索 | 添加、移除标签；按用户设置的名称做包含匹配；点击或选择标签筛选，可组合名称与多个标签。 |
| C06 | 阅读 | 点击进入漫画阅读，仅连续滚动阅读，页图之间无间距；边缘悬浮页码、页码跳转和继续上次进度。阅读进度为补充默认。 |
| C07 | 打包下载 | 导出“漫画名称.zip”，包内按阅读顺序生成“漫画名称/00001.webp”等文件；文件名进行安全处理。下载使用存储原件，不使用缩略图，不再压缩画质。 |
| C08 | 修改与删除 | 修改名称、标签；整本删除进入回收站。删除能力为补充默认。 |

已指定漫画目录内第一版按一层图片文件处理；隐藏系统文件如 .DS_Store 忽略。遇到嵌套目录或不能识别的文件时列出明细供处理，不能静默混入另一本或漏掉页面。重试上传不得产生重复页；一本中有失败页面时保持待完成状态，不把缺页的漫画当作导入成功。

**漫画上传必须满足 WebP 与无损要求。**

- 已有的有效静态 WebP 原样保存，校验文件内容及可解码性，不重复转码；下载后可核对原文件校验值。原文件若本来为有损 WebP，不声称重新恢复了已经损失的信息。
- 新上传的受支持非 WebP 静态图片转为无损 WebP。第一版支持常见 8 位 JPEG、PNG；不缩小尺寸、不裁剪，也不以目标文件大小降低画质。
- “无损”指解码后像素在明确的同一解码与颜色处理规则下保持一致，不代表保留 JPEG/PNG 原文件的二进制，也不能恢复源文件已经损失的细节。
- 使用 libwebp 真正的 lossless 模式，保留透明区域像素；不能用有损质量 100 或 near-lossless 代替。ICC、方向等元数据与像素校验分开处理。[官方编码选项](https://developers.google.com/speed/webp/docs/cwebp)说明了 lossless、exact 和 metadata 的行为。
- 转换结果可能变大；超过 WebP 尺寸上限、16 位 / HDR、动画或其他未支持输入，应明确报错，不悄悄降位深、取首帧或缩图。[WebP 官方 FAQ](https://developers.google.com/speed/webp/faq)说明了尺寸和无损转换的限制。
- 转换完成后重新解码并校验，再登记成功。转换失败保留任务信息并支持重试；不删除用户电脑中的来源目录。
- 首版默认仅漫画执行上述格式规范。图片、个人照片、个人私密照片和个人文件均保留原文件；预览图是独立衍生数据，不能替代原件。这个范围是根据当前上下文采用的实施默认值。

**小说作为独立模块，支持章节编辑和阅读。**

| 编号 | 功能 | 行为与验收 |
| --- | --- | --- |
| N01 | 小说管理 | 新建小说，填写和修改名称；每本有独立编号。 |
| N02 | 标签与搜索 | 给小说添加、移除标签；按小说名称搜索，按标签筛选，支持两者组合。 |
| N03 | 章节管理 | 新增、编辑、删除章节；每章有标题、正文和顺序，可调整章节顺序。 |
| N04 | 编辑模式 | 首版使用简单文本编辑器；正文与阅读视图分开，支持手动保存和自动保存，清楚显示保存中、已保存、保存失败。 |
| N05 | 内容保护 | 页面离开前提示未保存内容；保存失败不得显示成功。多设备同时编辑采用版本检查，避免后保存的旧内容静默覆盖新内容。保留可回退的近期修改记录。 |
| N06 | 阅读模式 | 章节目录、上一章 / 下一章、正文阅读、阅读进度；支持字号与浅色 / 深色外观。 |
| N07 | 删除与导出 | 删除章节可从回收站恢复；整本删除进入回收站。可按章节顺序导出整本 TXT，方便独立取回内容。 |

小说的名称、标签、章节标题、正文、顺序与修改记录都纳入一致性备份。编辑器先保证文字可靠保存，不要求富文本、在线协作或复杂排版。N05、N07 的回退与导出属于为避免内容丢失补充的默认功能。

**图片用于无需整理名称的日常图片浏览。**

| 编号 | 功能 | 行为与验收 |
| --- | --- | --- |
| I01 | 上传 | 单张、批量上传；无需输入标题、名称或标签。保留原始文件。 |
| I02 | 列表 | 缩略图网格 / 瀑布流，按上传时间展示，滚动加载；点开查看大图。 |
| I03 | 随机浏览 | 随机照片墙，进入后随机排列；滚动继续加载，“换一批”重新打乱；同一轮浏览避免重复，全部看完后可开始新一轮。 |
| I04 | 下载 | 单张下载原文件，批量选择打包下载；保留可用的原文件名，重名时安全区分。 |
| I05 | 删除 | 单张或批量删除进入回收站，便于清理。 |

本模块不提供名称输入、名称搜索、标签或标签搜索。内部仍保存稳定编号、原始文件名、格式、大小及校验值，以便下载和验证；这些不是用户必须维护的字段。随机浏览仅取本模块，不混入个人照片或私密照片。

**个人照片只提供上传备份和简单列表。**

| 编号 | 功能 | 行为与验收 |
| --- | --- | --- |
| P01 | 上传 | 支持批量上传，原始文件字节不变，保留原格式与已有元数据。 |
| P02 | 列表 | 简单缩略图列表 / 网格，点击查看；格式暂不支持预览时仍保留原文件并显示文件卡片。 |
| P03 | 备份 | 自动纳入备份，显示上传完成及最近一次成功备份状态；失败或尚未备份不能显示为已保护。 |
| P04 | 取回与清理 | 支持原图下载、批量取回和回收站删除。 |

无需名称、标签、搜索或随机浏览。首版不增加相册管理、人脸识别、地理位置地图等功能。P04 是保证备份资料可取回的补充默认；个人照片不因为生成预览图而修改原件。

**个人私密照片拥有与图片相同的浏览方式，并独立加密保护。**

| 编号 | 功能 | 行为与验收 |
| --- | --- | --- |
| S01 | 解锁 | 登录后还需保险库口令；未解锁时不显示照片、缩略图、原文件名或随机浏览结果。 |
| S02 | 上传与下载 | 解锁后单张 / 批量上传、原文件下载、批量打包；原文件保留字节，加密落盘。 |
| S03 | 列表与随机 | 解锁后提供缩略图列表、大图查看和随机照片墙，随机规则与图片模块一致。 |
| S04 | 数据隔离 | 随机池只含本模块；原图、缩略图、原文件名及敏感元数据受同一保险库保护。 |
| S05 | 锁定与删除 | 闲置超时或退出后锁定，隐藏预览并停止后续读取；删除进入受保护回收站。 |

不要求名称、标签或搜索。服务端不持久化明文预览或原件临时文件；浏览器不使用持久化离线缓存保存私密内容，锁定时清理应用持有的预览。下载到用户设备的文件由用户自行保管，系统不能远程撤回已经下载的副本。

**个人文件作为包含敏感资料的备份空间。**

| 编号 | 功能 | 行为与验收 |
| --- | --- | --- |
| F01 | 上传 | 支持任意文件及批量上传，按原始字节保存，不转码或解析修改内容。 |
| F02 | 名称 | 每个文件有名称，默认使用原始文件名，可修改；名称与物理存储路径分离，保留原始格式信息。 |
| F03 | 列表与搜索 | 显示名称、类型、大小、上传时间及备份状态；按名称包含匹配搜索。 |
| F04 | 下载 | 单个原文件下载及批量打包取回，校验内容与上传时一致。 |
| F05 | 删除 | 支持单个、批量删除并进入回收站，可恢复；清空或永久删除需明确操作。 |
| F06 | 隐私默认 | 因内容可能包含敏感文件，首版默认整个模块加密，名称与文件内容一起保护；解锁后才能列表、名称搜索、下载或删除。 |

个人文件与个人私密照片使用同一个保险库解锁会话，界面保留两个入口。文件名搜索在解锁后的受保护数据上完成，不在普通 SQLite 索引或日志留下明文名称。恢复码等可作为已有文件存入此处，当前范围不另建密码管理器或恢复码专用模块。F04、F06 为补充默认。

**公共规则只围绕可靠上传、取回和备份补充。**

| 编号 | 功能 | 默认规则 |
| --- | --- | --- |
| G01 | 登录与访问 | 单用户登录，局域网 HTTPS；原件、预览、下载、任务结果均需鉴权。 |
| G02 | 标签 | 仅漫画、小说提供；去除首尾空格，不重复绑定。首版多标签同时满足（AND），名称条件再与标签结果取交集；清除条件恢复全部。 |
| G03 | 搜索 | 漫画和小说搜索其显示名称；个人文件搜索其名称。均采用名称包含匹配、拉丁字符忽略大小写。无跨模块全局搜索，无隐私名称泄漏。 |
| G04 | 任务反馈 | 显示上传 / 转码 / 打包 / 备份进度、失败文件与原因；支持重试，任务结果持久化。分块上传记录已完成块，大文件中断后可继续。 |
| G05 | 重复与重名 | 校验值用于检查完全相同的内容，并在各自模块内提示；不自动删掉用户上传。不因同名覆盖旧文件，也不跨普通与加密区域共用明文文件对象。 |
| G06 | 回收站 | 默认保留 30 天，可恢复；私密内容仍加密且解锁后才可查看。清空当前数据不会立即清除历史备份中已有的版本。 |
| G07 | 下载可靠性 | 批量打包后台执行，失败可重试；私密包流式输出或加密暂存，不能在公共缓存目录落明文 ZIP。 |
| G08 | 性能与展示 | 六类列表均分页 / 增量加载，图片使用缩略图；转码和解码限制并发及资源占用，不一次载入全部文件。适配桌面和手机浏览器。 |
| G09 | 存储检查 | 上传前检查空间；外置数据盘缺失或身份不符时停写并提示，不能创建同名空目录继续运行。 |

保险库采用服务端解锁，前提是运行主机可信；此方案不承诺防御已经被控制的主机。系统自动启动与备份不等于自动解锁保险库。

**第一版的验收应覆盖以下实际操作。**

1. 上传目录 1，内含 00001.webp、00002.webp：得到一本漫画，预览为第一页，阅读顺序正确。将名称改为测试书名后，名称搜索立即使用新名称。
2. 给漫画和小说分别添加标签，通过名称 + 标签准确筛选；未启用搜索的图片、照片页面不出现无用搜索字段。
3. 上传支持的 JPEG / PNG 漫画页，得到通过解码像素校验的无损 WebP；已有 WebP 上传下载校验值一致。失败或不支持输入不会被静默跳过。
4. 下载整本漫画 ZIP，解压后页序完整、原件可读、没有用低清缩略图替代页面。
5. 新建小说，新增、修改、排序、删除并恢复章节；保存状态可信，阅读模式按正确章节顺序显示，刷新后保留已保存内容。
6. 图片可以上传、列表浏览、随机照片墙浏览和原件下载；同一随机轮次不重复加载，且不混入另外两类照片。
7. 个人照片上传并备份后，取回文件校验值与原文件一致；无需维护名称、标签或相册。
8. 锁定时私密照片和个人文件的内容、名称、预览与搜索结果均不可访问；解锁后私密照片可随机浏览，个人文件可按名称查找、下载、删除和恢复。
9. 断网、空间不足、上传中断、转码失败均有明确状态，重试不制造重复记录；不能把部分完成标为全部成功。
10. 使用发布包、备份和独立恢复材料，在空数据目录恢复六类内容及其名称、标签、章节、页序；核对文件并成功解锁保险库。

实施可以分阶段交付，但上述六个模块的用户明确需求都属于第一版完整范围。建议先打通存储、登录、上传与恢复，再完成漫画、小说、图片和个人照片，随后交付通过隐私验证的私密照片与个人文件，最后验证安装与整机恢复。测试与开发使用合成数据，不把真实文件、恢复码、私钥、数据库或备份提交到仓库。
