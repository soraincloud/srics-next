# 普通文件

2026-10-04 新增独立“文件”模块，位于网页资料库菜单。已有“个人文件”继续保留在保险库，没有自动移动、解密或混入普通列表。

## 使用

- 登录后即可上传和访问，无需保险库口令。
- 单个或批量上传任意格式，单文件最多 10 GiB；支持空文件与明确选取的隐藏文件。
- 名称默认取原文件名，单文件上传时可设置名称，入库后可改名；按名称搜索。下载保留原始文件名与字节。
- 列表显示名称、原文件名（名称改动时）、大小与上传日期。点击“选择文件”才显示选择框，可批量下载或移到回收站。
- 删除进入公共回收站，可恢复；彻底删除需要确认。

普通文件在资料盘中不使用保险库加密，应把敏感资料上传到“个人文件”。网页下载仍需要登录；任意文件作为附件下载，不执行上传的 HTML 或脚本。

## 保存与恢复

普通文件与其他普通资料共用 `objects/<随机对象编号>`、SQLite 索引和 8 MiB 上传分块。模块编号为 `attachments`；既有加密个人文件仍为 `files`。原件用 SHA-256 核验，不转码、不压缩、不生成缩略图；大文件流式合并，失败文件不会登记为完成。

普通文件、名称和回收站状态自动纳入现有统一加密备份。仍然只需要同一种完整备份与恢复 JSON，不增加新密钥。灾难恢复界面可查看和导出普通文件原件。

资料索引版本从 5 升到 6，首次打开旧目录前保留 `staging/before-files-*.db` 一致性索引副本。升级不移动已有对象；旧程序会拒绝打开新版资料库，避免旧版本清理不认识的文件引用。

## 验证

覆盖超过 64 MiB 的分块上传、重启续传、空文件、改名冲突、删除恢复、快照保留、内容校验失败、登录及 CSRF 边界、同名文件批量下载，以及仅使用统一备份包和恢复 JSON 在全新配置下恢复八个模块的原件。
